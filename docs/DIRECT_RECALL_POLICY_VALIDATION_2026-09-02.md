# 私聊撤回独立配置：实现与验证

日期：2026-09-02。环境：Windows / PowerShell 7.6.4、FVM Flutter 3.44.8。

## 配置与行为

- 后台「系统设置 → 消息、撤回与文件」提供三项独立设置：私聊撤回、群聊撤回、消息编辑。
- 新增 `directRecallMinutes`：默认 1440，允许 1–10080 整数分钟；原 `messageRecallMinutes` 仅控制编辑，默认 2，已有数值不变。`groupRecallMinutes` 保持独立。
- 沿用 `im_settings`、后台设置 GET/PUT 及公开 `/v2/config/auth`，无新表或数据库迁移。旧数据库缺少新键时，服务端、后台和 Flutter 均采用 1440。
- App 撤回调用仍走 `/v2/messages/{id}/recall`；私聊只允许原发送者操作，即使对方成员记录带管理员角色也不放行。按服务端发送时间比较，恰好到达时限允许。
- 已过期及系统消息不可撤回；重复请求幂等。后台审核撤回保留原超时处理能力。编辑及群聊规则不受私聊配置影响。
- Flutter 四端共用独立私聊策略；私聊双方仍显示「消息已撤回」，不使用群管理提示过滤。只更新扩展和 CMD，不修改 WuKongIM 原文。
