# 青蛙呱呱 1.0.3

- Flutter 版本：`1.0.3+4007`。
- Android：`com.fd.kuailiao`，ARM64 Release，沿用已有发布签名。
- iOS：推送 `main` 后由现有 GitHub Actions 构建签名 IPA；构建完成不等于第三方企业分发平台已更新。

## 更新内容

- 修复大群成员目录不完整导致的昵称、头像及个人资料访问问题。
- 修复失败消息重试时误用旧发送回执的问题，失败消息支持明确的重新发送操作。
- 会话列表与聊天顶部为普通群聊增加“群聊”标签和多人头像角标，单聊与业务频道保持原样。
- 合并此前已完成的在线状态、群成员管理、群历史可见性、撤回策略、消息提示及后台 IP 查询功能。
