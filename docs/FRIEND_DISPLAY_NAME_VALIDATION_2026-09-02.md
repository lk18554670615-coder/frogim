# 好友备注优先显示

日期：2026-09-02。环境：Windows / PowerShell 7.6.4、FVM Flutter 3.44.8。

## 实现范围

- `AppUser.displayName` 提供备注（去除首尾空白）/公开昵称回退；控制器统一按当前联系人 ID 解析，避免已打开页面继续使用旧备注。清空备注或删除好友后，不读取旧对象中的私人备注。
- 联系人列表按显示名称进行拼音分组及排序；会话列表、聊天标题、消息发送者、聊天信息成员、个人资料、搜索结果、置顶与收藏统一使用备注。
- 群成员管理保留原有群昵称回退：好友备注 → 群昵称 → 公开昵称。群会话本身的群名称不变。个人资料中有备注时同时展示公开昵称。
- 创建群聊、添加成员、@ 成员、发送名片、转发对象、朋友圈分享对象及可见范围选人面板使用同一规则。合并转发记录的本地发送者展示也支持备注。
- 改备注通知会刷新已打开的聊天、资料、列表和选择面板；搜索继续支持公开昵称、备注及已有账号字段，不改变目标用户/会话 ID。
- 仅在渲染时使用备注，不修改 `AppUser.name`、原始会话标题、消息 `senderName` 或历史消息快照。名片、引用及 @ 消息仍发送公开信息；转发仍只提交原消息 ID 和目标会话 ID。群内系统提示原文及服务端推送内容不改写。
- 不修改服务端、协议、数据库、普通用户身份或好友关系的存储方式。保留此前群管理提示、撤回策略、历史权限和 PC 滚动修改。

## 回归中修正的相关问题

既有转发队列测试发现：未打开过的群没有内存历史，已确认发送结果的摘要会被群提示过滤回退为空会话文案。现在以服务端确认的转发消息作为缺少内存历史时的摘要候选，仍执行统一可见性过滤；已有缓存（包括撤回状态）优先。不会把这几条转发结果作为完整历史写回磁盘，避免覆盖原缓存。新增对应回归断言，原 125 目标并发转发用例恢复通过。
