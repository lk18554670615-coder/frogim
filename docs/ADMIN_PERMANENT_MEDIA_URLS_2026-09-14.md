# 管理后台永久媒体地址

## 修复范围

- 数据库继续保存稳定的 `mediaId` 和对象键，不保存 MinIO/S3 临时签名 URL。
- 管理后台用户头像、群头像、成员头像、业务频道头像、邀请关系、登录日志、朋友圈、表情包及聊天审核中的图片、视频、视频封面和文件统一返回固定业务 URL。
- “文件与存储”页面增加“直接访问”，便于验证已完成媒体。
- 普通客户端原有的登录态媒体权限链路保持不变。

## 直接访问语义

固定 URL 采用 `/v2/media-public/{mediaId}/{signature}/{content|cover}`。签名由服务端根据媒体 ID、资源类型和服务端密钥确定性生成，不包含过期时间；请求由 Go 服务直接流式读取私有对象存储，不暴露桶地址或存储凭据，并支持视频字节范围请求。

该 URL 是持有者凭证：无需登录即可直接访问，无法仅通过枚举媒体 ID 生成有效地址，但任何获得完整 URL 的人都能访问。服务端签名密钥必须持久保存；更换密钥会使既有固定 URL 失效。

## 验证

- 固定地址重复生成结果相同，且不包含 `expires`、`X-Amz-*` 等临时参数。
- 无登录可直接读取图片／视频；视频 Range 请求返回 `206` 和正确 `Content-Range`。
- 修改签名或混用正文、封面签名返回 `404`。
- 后台消息中的历史临时 URL 和不可信封面字段会被稳定地址及服务端媒体关联覆盖。
