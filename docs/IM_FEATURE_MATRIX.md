# 邻里通讯完整功能矩阵

更新日期：2026-08-13

状态：`完成` 已有真实链路和测试；`进行中` 正在实现；`待补` 尚未达到上线标准；`外部依赖` 需要短信、推送、TURN 或商店凭证。

## 对照来源

- Apple Messages：编辑、撤回、行内回复、已读、输入状态、群管理等。
- Telegram：跨端同步、大群、管理员权限、置顶、搜索、文件和音视频通话等。
- 飞书即时消息：多类型消息、Pin、加急、消息编辑、群协作和管理后台等。
- 微信常用交互：会话左滑管理、单聊/群聊、收藏、多选逐条/合并转发、群公告和聊天信息。微信相关条目以实际客户端回归为准，不依赖非官方文章作为最终验收依据。
