# 群管理员入口与设置验证（2026-09-02）

## 实现

- 路径：聊天信息 → 群聊资料与管理 → 群管理员。
- 展示管理员人数；群主可按昵称、备注或呱呱号搜索成员，通过开关设置或取消管理员。
- 群主、现有管理员排序靠前；管理员和普通成员仅查看群主及管理员，不展示任命开关。
- 设置与取消均需确认；等待接口返回时禁止重复提交，失败显示原因且不伪装成功。取消管理员保留成员身份。
- 原群成员菜单复用相同确认、提交与反馈逻辑。
- 角色修改成功及群成员 CMD 触发刷新；旧请求结果不会覆盖较新成员列表。页面关闭、控制器销毁后不继续更新界面。
- 继续使用现有 `PUT /v2/channels/groups/{id}/members/{userId}/role`，请求仅包含 `admin` 或 `member`。未改变服务端规则：只有群主能任命管理员，不能经此接口修改群主身份。
- 保留现有 Flutter 主题、成员资料入口和手机/桌面共享页面。
