# 语音录制与发送动效验证

日期：2026-09-02。范围仅 Flutter 客户端；未提交、推送、部署或修改强制更新策略。

## 实现

- 输入栏上方的非模态浮层，准备、录音、取消和处理状态；保留 800ms 最短录音、60 秒上限、上滑 64dp 取消和松手试听。
- 通过 `record 7.1.1` 的 `getAmplitude()` 每 100ms 获取真实音量，独立 notifier 刷新波形。读取失败退回静态指示，不使用随机数据。
- 浮层与草稿过渡 180ms，本页新发送语音入场 220ms / 上移 8dp。以 `clientMessageId` 消费一次；历史、ACK、重新进入和重试不重播。
- 本地队列持久化成功后调用 `onQueued`；准备文件或保存队列失败保留草稿，交给队列后由原重试流程持有文件。上传 100% 后仍等待消息 ACK。
- 遵循减少动态效果，并避免 Flutter 零时长 `AnimatedSize` 在布局期间触发重入断言。

## 自动化结果

- 126 项相关 Flutter 测试通过：录音状态、真实音量采样、权限/启动中松手、取消及滑回、时长边界、试听/丢弃、重复发送、文件和持久化错误、消息入场去重、ACK/重试、原聊天/通话/桌面行为。
- `flutter analyze --no-pub`：无问题。
- 新增录音、取消、草稿三个 Windows Golden 基线。手机 320px、桌面 1280px、深浅主题、200% 字体及减少动态效果有组件覆盖。
- 扩展视觉回归仍有 5 项既有页面基线不匹配：手机登录、探索、设置、桌面扫码登录、桌面会话工作台。包含先前入口移除和桌面外边距等差异；本次没有覆盖这些无关基线。

## Android 手机验证

设备：vivo V2403A（ARM64），包名 `com.fd.kuailiao`。

- 覆盖安装成功，未清除应用数据，保留登录。
- 在 `AndroidTest0828` 测试会话中实际录音，浮层显示时长和真实变化的音量波形，输入栏位置保持不变。
- 6 秒录音松手出现试听草稿，点击试听进入播放状态，丢弃后恢复按住说话。
- 上滑出现红色“松开取消”，松开后不创建草稿或发送消息；另一轮上滑后滑回恢复绿色并进入试听。

- 权限拒绝、60 秒边界、文件失败和重复点击主要由自动化覆盖；没有为测试而修改手机权限或制造生产服务故障。
- 送达后日志中出现过 IM Socket 短暂断连记录；本次不调整网络/服务端，也不把动效验证等同于网络稳定性验收。
