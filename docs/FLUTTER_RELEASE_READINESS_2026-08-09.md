# Flutter 发布就绪检查

本文件是客户端发布门禁清单，实际版本状态以当次测试、构建和真实服务器验收结果为准。

## 必须通过

- `flutter analyze` 无错误。
- `flutter test` 全量通过。
- Web、Android、iOS、macOS 目标平台至少完成对应发布构建。
- `APP_ENV=production`、`ENABLE_DEMO=false`，并配置真实 HTTPS API、用户协议和隐私政策。
- 登录、注册、验证码、密码重置、退出与凭据刷新使用真实接口。
- 单聊、群聊、消息顺序、重试、离线同步、撤回、引用、转发、文件和媒体链路完成真实环境验收。
- 音视频房间与短期令牌由服务端签发；客户端不保存服务端密钥。
- 推送密钥、签名文件、证书和密码不进入 Git。
- 管理后台和服务端操作有权限校验、失败提示和审计记录。
- 服务器 Web、后台和 API 容器健康，HTTPS、WSS 与所需音视频端口可达。

## 发布后验证

1. 使用两个真实测试账号分别从常规浏览器和手机登录。
2. 验证单聊、群聊、@成员、文件、图片、语音、视频和离线红点。
3. 验证好友申请、群邀请、群公告、禁言、踢人和解散等权限路径。
4. 验证管理后台的真实统计、用户详情、举报审核、公告和系统设置。
5. 重启前端容器后确认客户端仍能连接；重启服务节点后确认消息顺序和离线补偿正常。
6. 保存当次提交、容器镜像、测试记录和回滚点。

任何一项没有证据时，应标记为“待验证”，不能用推测替代发布结论。
