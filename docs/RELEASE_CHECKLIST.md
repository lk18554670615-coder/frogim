## 发布前

- [ ] 需求范围、功能矩阵和已知限制已经确认。
- [ ] 工作区无意外生成物，变更已经过代码审查。
- [ ] Go 测试、`go vet`、竞态测试通过。
- [ ] Admin 测试、TypeScript 检查和生产构建通过。
- [ ] Flutter analyze、测试、iOS/Android 候选包构建通过。
- [ ] 文档链接、Shell 语法和 Compose 配置检查通过。
- [ ] 数据库迁移已审阅，确认向前兼容且不自动执行 down migration。
- [ ] `.env.production` 权限为 `600`，无占位符、开发验证码或日志推送。
- [ ] `infra/scripts/verify-wukong-server-patch.sh` 已通过；自定义 WuKongIM 镜像已推送到受控仓库，`WUKONG_IMAGE` 固定为实际 `repository@sha256`，并记录构建来源与补丁摘要。
- [ ] 短信、个推/APNs/Android 厂商通道、LiveKit、对象存储与管理员 TOTP 已配置。
- [ ] LiveKit 的 7881/TCP 与 7882–7889/UDP 已在主机和云安全组放行，并完成跨网络音视频验证。
- [ ] PostgreSQL、WuKongIM 和 MinIO 完整备份完成，固定版本锁与校验值已复制到异机。
- [ ] 异地S3目标已启用，`_COMPLETE`最后写入，对象锁/保留策略和下载校验已验证。
- [ ] `nexachat_backup_last_status=1`、最近成功时间未陈旧且不存在非运行中的 `.incomplete-*`。
- [ ] 恢复演练在约定周期内完成，RPO/RTO 证据有效。
- [ ] 监控、告警接收人、值班和回滚负责人在线。

## 发布中

- [ ] 记录发布开始时间、旧镜像 ID、配置版本和数据库迁移版本。
- [ ] 执行 `make production-validate` 与 `make production-config`。
- [ ] 使用受控部署流程更新服务，不删除 volume。
- [ ] 观察迁移、启动、健康检查和错误日志。
- [ ] `/health`、`/ready`、HTTPS/WSS、安全响应头和未授权拒绝均正常。
- [ ] 完成双用户登录、好友、单聊、群聊、媒体、同步、撤回和后台登录冒烟。
- [ ] 使用真机验证前台、后台、杀进程离线通知及点击跳转。

## 发布后

- [ ] 观察错误率、延迟、连接数、队列、数据库、Redis 和存储容量至少 30 分钟。
- [ ] 确认公告、审核、审计和配置中心可用，密钥没有回显。
- [ ] 确认备份任务、证书续期和告警没有被部署破坏。
- [ ] 记录新镜像 ID、迁移版本、冒烟结果、异常与处理结论。
- [ ] 产品、QA、技术和运维完成上线签字。

## 回滚触发条件

出现持续登录失败、消息丢失/乱序、迁移错误、数据不可读、严重权限绕过、推送大面积失效或无法控制的错误率时立即停止继续发布。优先回滚应用镜像；数据库只按已验证的恢复方案处理，禁止临时执行 down migration。
