# 青蛙呱呱 1.0.5

- Flutter 版本：`1.0.5+4009`。
- 包名 / Bundle ID：`com.fd.kuailiao`，沿用原发布签名。
- Android：发布 ARM64 Release APK。
- iOS：推送 main 后触发既有 GitHub Actions 签名构建。未获得新企业安装地址之前，不修改 iOS 检查更新策略。

## 更新内容

- App、Web 和运营后台采用 Telegram 风格蓝白配色，客户端深色模式采用深蓝灰。
- Logo 与各端应用图标统一为蓝底白蛙，保留原青蛙造型。
- 包含已提交但尚未上线的五种群入群方式、普通成员好友邀请与管理员审核、群管理等改进。
- 后台用户详情支持邀请来源补绑和改绑；要求权限、理由及确认，拦截无效代码、循环关系和并发覆盖，并记录审计。
- 证书续期仅处理当前服务器 IP，成功后强制热加载 Caddy，避免旧 IP 续期失败或配置未变化导致线上仍使用旧证书。

## 验证与发布

- 主题及 Logo 的 Flutter、后台和资源测试见对应 2026-09-07 验证文档。
- 邀请来源真实 PostgreSQL 迁移、并发和回滚测试，Go 全量测试 / vet、后台 141 项测试、类型检查及构建通过。
- 数据库升级到 **65**，发布前必须备份；先服务端和后台，再 Web、Android 更新策略。
- 保留 Android 现有最低版本 `1.0.2`，仅更新最新版本及安装包地址，不额外提高强制更新门槛。
- 保留远端现有 IM、存储、推送及认证配置。本次发现远端仍使用历史开发验收配置，不能将本次部署宣称为生产安全配置验收通过。
- 不回滚数据，不清除用户记录，不改变 iOS 企业分发平台的已有安装地址。

产物哈希、服务器备份和上线检查结果另存发布记录，不将凭据、管理员会话或数据库备份提交到 Git。
