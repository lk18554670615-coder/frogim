## 对照原则

- 参考对象为唐僧叨叨官方管理端的公开菜单、源码路由和官方说明。

## 真实数据约束

1. 首页看板不在前端生成随机数或演示数据。
2. 核心指标由后端一次性聚合返回，并携带服务端生成时间。
3. 用户和群组列表使用服务端筛选与分页，不用浏览器端伪分页。
4. 未上报的数据明确显示“未上报”或“不适用”，不以 `0` 冒充真实结果。
5. 所有管理操作必须有服务端成功响应，失败时保留错误提示和重试入口。
