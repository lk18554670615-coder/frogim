# 邻里通讯移动端首发范围与上线门槛

> 状态（2026-08-09）：本文件保留为历史范围记录，已由[首发生产就绪审计](../../docs/FLUTTER_RELEASE_READINESS_2026-08-09.md)替代。音视频、推送、置顶、免打扰和账号注销等能力的当前状态以新报告及代码为准。

## 当前首发功能

- 手机验证码登录、会话恢复与安全退出。
- 单聊、群聊、联系人、好友申请、拉黑与举报。
- REST 401 单飞续签、原请求只重放一次；WuKong SDK 鉴权失效后重新获取 `ImSession`，普通断线指数退避。
- 文本、表情、引用回复；引用使用真实 `replyToId`，重新拉取历史后仍可显示引用正文。
- 相册、相机与文件系统选择；媒体按 `presign → PUT → complete → message` 上传，失败消息可重试。
- 已读、撤回、仅本机删除、批量选择删除、文本转发、加密本机收藏、聊天记录搜索。
- 本机消息缓存加密、登录凭据系统安全存储、深浅外观与动态字体。

## 已从生产 UI 移除

- 音视频通话与语音录制：服务端虽有 WebRTC 信令，但客户端没有经过真机验证的媒体栈、系统音频会话、来电流程与弱网恢复。
- 聊天置顶：服务端没有置顶接口。
- 通知免打扰：现有群成员 `mute` 是管理员限制成员发言，不能作为用户通知偏好。
- 通知设置：客户端尚未完成 APNs/FCM 设备注册、凭证与真机到达率验收。
- 账号注销入口：服务端没有用户自助注销 API；在补齐可验证的删除流程前不展示虚假入口。

## 服务端必须补齐的上线项

1. 媒体读取：当前只有上传和完成确认，没有受鉴权的签名 GET 或媒体代理下载地址。发送者可显示本机文件，其他设备会明确显示“暂无法下载”。
2. 账号注销：提供二次验证、撤销会话、异步数据删除与审计回执接口；这是允许创建账号的 App Store 应用的重要审核门槛。
3. 推送：配置真实 APNs/FCM 凭证、设备 token 生命周期、生产 webhook 密钥，并完成前台、后台、杀进程和 token 轮换真机验证。
4. 媒体安全：对任意文件开放前增加恶意软件扫描、内容安全、下载响应头与保留策略。
5. 合规材料：正式隐私政策、用户协议、客服与举报处置 SLA、数据导出/删除政策。

## 发布验收

- 自动化：`flutter analyze`、`flutter test`、iOS Simulator build、Android debug build 全部通过。
- 真机：相机/相册权限拒绝与恢复、100 MB 边界、断网续传策略、前后台 WuKong 恢复、弱网重复发送、iOS/Android 深色与大字体。
- 外部系统：生产 HTTPS/WSS、OTP、对象存储 CORS/签名、APNs/FCM、隐私政策 URL、App Store/Play Console 凭证均需由发布方提供并验收。

上述外部项未完成前，本仓库可以用于联调、内测和功能验收，但不能诚实地宣称已经具备商店生产上线条件。
